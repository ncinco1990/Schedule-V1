VALBEN Project Dashboard V11.0 — Professional PDF + Smart Calendar

BUILT FROM V10.9

PDF IMPROVEMENTS
- Generate PDF now asks:
  - Generate with Watermark
  - Generate without Watermark
- Optional watermark text:
  By Norman Cinco
- Watermark is intentionally subtle and diagonal so it does not interfere with reading.
- PDF footer/page number moved upward and inward from the paper edge to reduce printer clipping.
- Top-right project information uses a larger safe print inset.
- VALBEN logo is larger and placed inside a clean bordered logo area for stronger visibility.
- PDF remains a real data/vector report, not a screenshot.

BLOCKER INFORMATION IN PDF
- Added a Blocker Reason / Note column.
- When a task has an open blocker, the PDF can show:
  - Blocker type
  - Note / reason
  - Responsible party when a note is not present
  - Required By date
- The blocker reason is shown in a warm accent color so it can be found quickly without overwhelming the report.

SMART CALENDAR
- Activity names are removed from the monthly calendar cells.
- Each working day now shows only:
  - Colored arrow/status
  - FREE / LOW / MEDIUM / HIGH / FULL / OVERLOAD
  - Load percentage
  - Compact load bar
- Click any day to open the detailed activity list in the side panel.
- No Work / OFF days remain visually separate.
- 10 activities = 100% daily capacity.
