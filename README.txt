VALBEN Project Dashboard V11.1 — Frozen Weeks + Smart Wrap

BUILT FROM V11.0

1) SECOND HORIZONTAL MOVEMENT BAR
- Added a second horizontal Schedule navigator ABOVE the table/Gantt.
- The existing bottom navigator remains.
- Top and bottom bars are synchronized.
- Moving either bar moves the same complete Schedule canvas.
- Both bars include quick Table and Weeks buttons.

2) EXCEL-STYLE FROZEN HEADERS
- Schedule column headers remain visible while scrolling vertically.
- WEEK 1 / WEEK 2 / WEEK 3 and day/date headers also remain visible.
- This keeps the timeline reference visible while working farther down a long schedule.

3) ACTIVITY NAME SMART WRAP
- Task Name is now a wrapping editor instead of a single-line input.
- Short names remain one line.
- Longer names automatically expand to a second visible line.
- Rows are allowed to grow automatically.
- The Gantt Alignment Engine measures the new row height and keeps the activity bar aligned.

4) PDF TEXT WRAPPING
- Task Name column is wider in the PDF.
- Task Name can wrap across multiple lines instead of being cut.
- Blocker Reason / Note can also wrap across multiple lines.
- PDF row height increased to make the additional text readable.
- The V11.0 safe margins, logo, watermark option and blocker reason remain.

IPAD / IPHONE
- Both horizontal movement bars are touch-friendly.
- Frozen week/day headers remain available while scrolling.
- Task Name wrapping uses mobile-safe 16px editing text.
- Full Screen and 3-Week Fit remain supported.

NO SUPABASE MIGRATION REQUIRED.
