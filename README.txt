VALBEN Project Dashboard V10.9 — Direct PDF + Drag Reorder

DIRECT PDF
- Browser Print Preview and window.print workflow removed.
- Generate PDF creates a real 17 × 11 landscape PDF directly from Schedule data.
- It is not a screenshot.
- The report includes Project Name, Location, schedule table, predecessor/link fields, blocker indicator and vector Gantt bars.
- Long schedules continue automatically onto additional pages.

DRAG ACTIVITY ORDER
- Up / Down arrows removed.
- Use the compact ⋮⋮ handle to drag an activity with mouse, trackpad, iPad or iPhone.
- Drop above/below another activity.
- The Schedule can auto-scroll vertically while dragging.

AUTOMATIC ID RENUMBERING
- After drag reorder, IDs become 1, 2, 3, 4...
- Moving activity 12 to row 7 makes it ID 7.
- Deleting an activity also removes ID gaps.
- Predecessor references are remapped so dependencies remain attached to the same activity.
