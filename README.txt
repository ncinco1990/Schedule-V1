VALBEN Project Dashboard V12.5 - 14-Day Field Lookahead

NEW PRESENTATION STANDARD
The previous Professional Schedule has been evolved into a dedicated 14-Day Field Lookahead for superintendent / GC coordination.

ONE-PAGE TABLOID
- PDF is always one 17 x 11 inch landscape page.
- Selectable vector/text output through jsPDF.
- Adaptive row height/font sizing keeps the schedule on one page.
- Clean PDF is the recommended/default action.
- Optional By Norman Cinco watermark remains subtle.

TABLE
- ID
- Activity / Location
- Start
- Finish
- Duration shown as working days (wd) and calendar days (cd)
- Release / Coordination
- 14 daily Gantt columns

VISUAL STANDARD
- Dark navy headers
- Field work: blue
- Concrete: green
- Inspection: ochre
- Delivery: purple
- Curing: gray
- Sunday: darker gray shade
- Saturday: light gray shade
- Continuation outside period: left/right markers

NON-DESTRUCTIVE WORDING
The presentation layer standardizes common construction wording such as:
- Reinforcement
- Formwork
- PT Tendon Installation
- MEP Sleeves & Embeds
- Pre-Pour Inspection
- Concrete Placement
- Finishing
- Curing
- Stripping
Source task names/dates remain unchanged in the project data.

SEQUENCE / COORDINATION REVIEW
Checks include:
- Duplicate IDs
- Blank activity names
- Invalid/reversed dates
- No Work date conflicts
- Missing/self predecessor
- FS/SS/FF inconsistencies
- Concrete with no inspection activity found in the same inferred group
- *PROPOSAL to verify curing follow-up when no curing activity is found
- Saturday concrete/inspection resource confirmation
- Sunday start authorization warning for non-curing tasks
- Activities continuing before/after the horizon

COLUMN GROUPS
If a column activity contains 6+ recognizable column IDs, the presentation can abbreviate it as Group A/B while listing every detected ID in a footnote.
