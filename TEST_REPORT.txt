ISSUES FOUND AND CORRECTED
1. Rolling Lookahead horizon persistence
   - V11.3 saved the selected week count in browser storage, but currentProjectState()
     did not include horizonWeeks.
   - Fixed in V11.4.
   - Project state now includes the selected 1–12 week horizon.

2. System Diagnostics false Modal Layer failure
   - When Schedule was not in Full Screen, its computed z-index could be "auto",
     which was parsed as NaN and incorrectly reported as a failure.
   - Fixed in V11.4.

3. Duplicate PDF generation
   - Added a generation lock so repeated clicks on the watermark choice cannot
     start two PDF generations simultaneously.

4. Launch Preflight
   - Added Guide → System Diagnostics → Launch Preflight.
   - It checks Supabase/jsPDF availability, Blockers, Schedule/Gantt counts,
     planning horizon and project-state persistence.
