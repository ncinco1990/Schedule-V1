CURRENT VERSION · V14.0

Current Version

Updated Oct 8, 2026
VALBEN Project Dashboard V14.0
Base: V9 + dependencies + themes + continuous Gantt + cloud sync + login/multi-project + V10.0 project identity and password recovery.
Use this page as the reference for what each field, link, status and color means. Future changes can be added to the Version History below.

Gantt Colors

Gray Scheduled / Not Started Dark Gray In Progress Green Completed Red Delayed Yellow Blocked

Sunday and any custom No Work day are OFF and do not count as working days.

Dependency Links — Microsoft Project Style

Predecessor + Link
LinkMeaningHow it behavesTypical construction example
FSFinish-to-StartThe successor cannot start until the predecessor finishes. The app places it on the next available working day.Finish footing rebar → start concrete placement.
SSStart-to-StartThe successor starts when the predecessor starts.Start excavation → start dewatering at the same time.
FFFinish-to-FinishThe successor finish date is aligned to the predecessor finish date.Formwork cleanup and stripping activities planned to finish together.
Predecessor is the ID of the activity that controls another activity. Example: Activity 12 with Predecessor 8 and Link FS means Activity 12 starts after Activity 8 finishes.

Status Meanings

Not StartedActivity has not begun.
In ProgressActivity has started but is below 100%.
CompletedActivity is 100% complete. The ✓ button also sets this status.
DelayedActivity is behind the planned schedule / needs attention.
BlockedActivity cannot proceed because of an external issue or dependency.

Schedule Controls

↑ ↓Move an activity up or down in the schedule.
✓Mark the activity Completed and set it to 100%.
×Delete the activity.
DurationNumber of working days. Sunday / No Work days are excluded.
Start / FinishChanging dates updates the Gantt and linked successor activities.

Calendar / No Work

  • Sunday is always a No Work day.
  • Mark / Unmark No Work lets you exclude another date from the working calendar.
  • No Work dates do not count toward activity Duration.
  • Gantt bars do not cover OFF dates.
  • Daily calendar capacity uses 10 activities = 100%.
  • V11.0 calendar cells no longer show activity names. Each day shows only a load bar, percentage and colored arrow/status. Click the day to see the activity list.
  • 1 activity = 10%, 5 = 50%, 10 = 100%; over 10 is marked OVERLOADED.
  • Calendar load changes from green → yellow → red as workload increases.

PDF Reports

  • Generate PDF creates a real 17 × 11 landscape PDF directly from project data.
  • V11.0 asks whether to include the subtle watermark By Norman Cinco.
  • The PDF header now uses larger safe print margins and a stronger VALBEN logo area.
  • Open blockers print their Blocker Reason / Note, including type, note and Required By date when available.
  • The footer and page number are moved inward/upward so printers do not clip the text.
  • The PDF is generated from schedule data and vector Gantt bars, not from a screenshot.

Appearance / Themes

Updated in V9.6

Theme dropdown changes the main application accent without using extra sidebar space. Available themes: Classic Blue, Teal, Green, Orange, Purple and Slate.

Dark Background changes the working interface to a dark background for low-light use. Direct PDF output uses a clean white report background.

Minimal Rounded UI applies softer spacing and rounded / oval corners across cards, controls, tables, calendar, preview and schedule areas while keeping the same work-line colors.

Gantt Bars lets you choose Status Colors or a fixed Blue, Teal, Green, Orange, Purple, Red, Slate or Custom color. The Status field keeps its own status meaning even when a fixed Gantt color is selected.

Continuous Gantt now draws each task as one continuous bar across consecutive working days. The bar only breaks at Sunday or another No Work / OFF day.

Theme and dark-mode selections are saved in the browser and restored the next time the app is opened.

Accounts / Projects

New in V9.9

Account Login uses Supabase Auth. Sign in with the same email and password from any browser to access your projects.

Projects keeps each job separate. Every project has its own activities, dates, dependencies, No Work dates, logo, Gantt, Calendar and Lookahead.

The old shared Sync Code is no longer required for normal V10.0 use. Project data is protected by account-based Row Level Security in Supabase.

V10.0: Change the project name or location directly at the top of Schedule. The change automatically updates the project selector, page header and Rolling Lookahead.

Forgot Password: use the link on the Sign In screen to receive a reset email and choose a new password.

Mobile V10.1: on iPad and iPhone use the bottom navigation bar. In Schedule, swipe horizontally to move through the activity table and Gantt. On iPhone, the Calendar also supports horizontal swipe so the seven-day layout stays readable.

V10.2: use Blocker on any activity to record what is stopping it, Needs Attention on Dashboard to see urgent work, and Set Baseline before execution to compare current finish dates against the approved plan.

V10.3 Schedule: Full Detail shows every editable schedule column. Horizon Fit keeps Task Name, Status and Blocker beside the full 21-day Gantt. The bottom schedule bar scrolls the entire table + timeline together. iPad and iPhone default to Horizon Fit for easier field use.

V10.4 Focus Mode: press Full Screen while working in Schedule. The rest of the dashboard is hidden and the Schedule uses the full browser viewport. Use − / % / + to zoom. Press Exit · Esc or the keyboard Escape key to return. On iPad/iPhone the Focus workspace automatically favors Horizon Fit.

V10.5 Full Screen: the complete Schedule interface stays visible in the workspace, including Project Name, Project Location, search/filters, No Work controls and the full Gantt. Delete confirmations no longer exit Full Screen. The same Full Screen button becomes Exit Full Screen; Esc also exits.

V10.6 Columns: in Full Detail, drag the separator on the right side of a column header to resize it like Excel. Double-click the separator to Auto Fit that column. Auto Fit Columns sizes the full table from the current content, while Reset Columns restores the recommended widths. Task Name grows automatically while typing, up to a safe maximum so the Gantt remains usable.

V10.7 Stability: Blocker Type now uses visible buttons instead of the browser dropdown, which is more reliable on Windows, iPad and iPhone. If another problem appears, open Guide → System Diagnostics → Run Diagnostics and copy the report.

V10.8 Gantt: each Schedule activity row is matched to its Gantt row by activity ID. The app measures the real row height and keeps the corresponding bar centered on that row, preventing drift after 5, 10 or more activities. Diagnostics now checks Gantt rows, bar segments and alignment.

V10.9 Ordering: use the ⋮⋮ handle to drag an activity to a new row. When the drop is completed, the Schedule renumbers all IDs sequentially. Example: moving activity 12 into row 7 makes it ID 7, and predecessor IDs are automatically remapped to preserve the same dependency relationships.

V11.2 Schedule: the extra top horizontal navigator and frozen headers were removed. The Schedule now uses the simpler bottom horizontal navigator only. Long Task Names still automatically use a second line rather than forcing the column wider.

V11.2 PDF text: Task Name and Blocker Reason / Note continue using wrapped multi-line cells so longer descriptions are much less likely to be cut in the generated PDF.

V11.3 Rolling Lookahead: the planning report is no longer limited to a fixed three-week period. Use − Week or + Add Week to choose from 1 to 12 weeks. The Schedule, Rolling Lookahead and generated PDF all use the same selected horizon. Longer PDF horizons automatically continue into additional readable timeline windows instead of squeezing all days onto one page.

V11.4 Launch Candidate: use Guide → System Diagnostics → Launch Preflight before publishing a new build. It verifies core libraries, project state, Blockers, Schedule/Gantt render counts and the adjustable horizon.

V11.5 Add Activity: pressing + Add Activity now clears active Schedule search/status/category filters first, creates the new row, opens Schedule and focuses the Task Name field. This prevents the new row from being created but hidden by a filter.

14-Day Field Lookahead

One-page tabloid / field coordination

14-Day Field Lookahead is a one-page 17 × 11 field presentation derived from the current Schedule without changing source IDs, activities or dates. It uses a compact table (ID, Activity / Location, Start, Finish, working/calendar duration and Release / Coordination) plus a daily 14-day Gantt.

Presentation wording is standardized non-destructively for common construction terms such as reinforcement, formwork, PT tendon installation, pre-pour inspection, concrete placement, finishing, curing and stripping. Saturday/Sunday are shaded; concrete, inspections, deliveries and curing use dedicated restrained colors; activities outside the horizon receive continuation markers.

Coordination & QA Review reports possible sequence gaps, weekend items, dependency inconsistencies, missing inspection/curing follow-up checks and continuation outside the period. *PROPOSAL notes never modify dates automatically. The PDF is always a single tabloid page and includes Prepared by Norman Cinco | ValBen Construction.

Deliveries

V14.0

Focused field workflow: weekly list on the left, connected week calendar on the right and the selected delivery form below. Phone layout switches between List and Calendar and opens the form as a bottom panel.

Phase and Pour stay independent. PH is never converted into a Pour and P/PR is never converted into a Phase. Control codes are stored as text arrays so leading zeros are preserved. Supplier Processed/Shipped is separate from field Scheduled/Partial/Received/Canceled.

Excel import: preview is mandatory before import. Re-import protection uses a stable natural import key (provider + material + level + pour + phase + control codes). Rows with missing material/control code or ambiguous P/PH data are flagged instead of auto-corrected.

Field Coordination Center

V13.0

One record, connected views: each delivery, concrete program, inspection or follow-up is stored once in Supabase and rendered in the Coordination Schedule and Day/Week/Month Calendar. Rescheduling from the calendar updates the same record; relative reminders move with the new execution date.

Concrete: concrete supplier, CY, mix, truck frequency, pump, hose, pre-inspection and pending confirmations are stored on the concrete record. Optional Confirm Concrete / Confirm Pump / Confirm Inspection dates create separate follow-up activities so one confirmation never implies the others.

Sharing: Share Week can generate a PDF, prepare a mail-client draft, or create a 30-day read-only snapshot link. Mail-client opening is logged as client_opened, not sent. Actual server-side email requires an external email provider secret. Closed-app push notifications are also not active until a push/VAPID backend is configured.

Daily Field Report · V12.5
