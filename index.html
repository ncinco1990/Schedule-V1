Guide / Version Notes

Current version, feature meanings, color rules, design updates and change history.

CURRENT VERSION · V10.3

Current Version

Updated Sep 1, 2026
VALBEN Project Dashboard V10.3
Base: V9 + dependencies + themes + continuous Gantt + cloud sync + login/multi-project + V10.0 project identity and password recovery.
Use this page as the reference for what each field, link, status and color means. Future changes can be added to the Version History below.

Gantt Colors

Gray Scheduled / Not Started Dark Gray In Progress Green Completed Red Delayed Yellow Blocked

Sunday and any custom No Work day are OFF and do not count as working days.

Dependency Links — Microsoft Project Style

Predecessor + Link
LinkMeaningHow it behavesTypical construction example
FSFinish-to-StartThe successor cannot start until the predecessor finishes. The app places it on the next available working day.Finish footing rebar → start concrete placement.
SSStart-to-StartThe successor starts when the predecessor starts.Start excavation → start dewatering at the same time.
FFFinish-to-FinishThe successor finish date is aligned to the predecessor finish date.Formwork cleanup and stripping activities planned to finish together.
Predecessor is the ID of the activity that controls another activity. Example: Activity 12 with Predecessor 8 and Link FS means Activity 12 starts after Activity 8 finishes.

Status Meanings

Not StartedActivity has not begun.
In ProgressActivity has started but is below 100%.
CompletedActivity is 100% complete. The ✓ button also sets this status.
DelayedActivity is behind the planned schedule / needs attention.
BlockedActivity cannot proceed because of an external issue or dependency.

Schedule Controls

↑ ↓Move an activity up or down in the schedule.
✓Mark the activity Completed and set it to 100%.
×Delete the activity.
DurationNumber of working days. Sunday / No Work days are excluded.
Start / FinishChanging dates updates the Gantt and linked successor activities.

Calendar / No Work

  • Sunday is always a No Work day.
  • Mark / Unmark No Work lets you exclude another date from the working calendar.
  • No Work dates do not count toward activity Duration.
  • Gantt bars do not cover OFF dates.
  • Daily calendar capacity uses 10 activities = 100%.
  • 1 activity = 10%, 5 = 50%, 10 = 100%; over 10 is marked OVERLOADED.
  • Calendar load changes from green → yellow → red as workload increases.

Reports / Printing

  • 3-Week Lookahead shows the upcoming three calendar weeks.
  • Print Preview lets you review the report before printing.
  • Save PDF / Print opens the browser print window.
  • Dependency predecessor IDs and link types are included in the Lookahead.
  • Dependency connector lines appear on the Lookahead Gantt.

Appearance / Themes

Updated in V9.6

Theme dropdown changes the main application accent without using extra sidebar space. Available themes: Classic Blue, Teal, Green, Orange, Purple and Slate.

Dark Background changes the working interface to a dark background for low-light use. PDF/print output remains white.

Minimal Rounded UI applies softer spacing and rounded / oval corners across cards, controls, tables, calendar, preview and schedule areas while keeping the same work-line colors.

Gantt Bars lets you choose Status Colors or a fixed Blue, Teal, Green, Orange, Purple, Red, Slate or Custom color. The Status field keeps its own status meaning even when a fixed Gantt color is selected.

Continuous Gantt now draws each task as one continuous bar across consecutive working days. The bar only breaks at Sunday or another No Work / OFF day.

Theme and dark-mode selections are saved in the browser and restored the next time the app is opened.

Accounts / Projects

New in V9.9

Account Login uses Supabase Auth. Sign in with the same email and password from any browser to access your projects.

Projects keeps each job separate. Every project has its own activities, dates, dependencies, No Work dates, logo, Gantt, Calendar and Lookahead.

The old shared Sync Code is no longer required for normal V10.0 use. Project data is protected by account-based Row Level Security in Supabase.

V10.0: Change the project name or location directly at the top of Schedule. The change automatically updates the project selector, page header and Three-Week Lookahead.

Forgot Password: use the link on the Sign In screen to receive a reset email and choose a new password.

Mobile V10.1: on iPad and iPhone use the bottom navigation bar. In Schedule, swipe horizontally to move through the activity table and Gantt. On iPhone, the Calendar also supports horizontal swipe so the seven-day layout stays readable.

V10.2: use Blocker on any activity to record what is stopping it, Needs Attention on Dashboard to see urgent work, and Set Baseline before execution to compare current finish dates against the approved plan.

V10.3 Schedule: Full Detail shows every editable schedule column. 3-Week Fit keeps Task Name, Status and Blocker beside the full 21-day Gantt. The bottom schedule bar scrolls the entire table + timeline together. iPad and iPhone default to 3-Week Fit for easier field use.

Version History

Project change log
V9
Daily workload capacity. Calendar standardized to 10 activities = 100%, with green → yellow → red workload indication and OVERLOADED for more than 10.
V9.1
Dependencies added. Predecessor field, FS / SS / FF links, Gantt connector arrows, automatic successor rescheduling, cascading dependency chains and circular-link protection.
V9.2
Guide / Version Notes added. New permanent reference tab containing current version, feature definitions, link meanings, color/status guide, calendar rules and version history.
V9.3
Appearance controls added. Six color palettes, persistent theme selection and Dark Background mode. Printing remains white for clean PDF output.
V9.4
Theme selector compacted. The six visible palette buttons were replaced with one dropdown and a live color preview, reducing sidebar space while keeping all themes.
V9.5
Minimal Rounded UI. The interface was visually simplified and all major sections were updated with more rounded / oval corners, softer shadows and cleaner spacing, while keeping the same schedule work colors and status colors.
V9.6
Continuous Gantt + bar colors. Task bars are now continuous across consecutive working days and only split at OFF / No Work dates. Added a compact Gantt color palette with Status Colors, preset colors and a custom color picker.
V9.7
Supabase Cloud Sync. Added shared cloud storage for schedule activities, dependencies, No Work dates and the project logo. A private Sync Code connects multiple browsers to the same project state.
V9.8
Web hosting architecture corrected. The frontend is prepared for a dedicated web host while Supabase remains the cloud-sync backend. The Cloud Sync API now uses a fixed Supabase endpoint so synchronization works from any hosted domain.
V9.9
Login + Multi Project. Added Supabase email/password authentication, private account-based projects, a project switcher, project creation/deletion and separate cloud schedules for each job.
V10.0
Project Identity + Password Recovery. The Schedule now has editable Project Name and Project Location fields that update the active project everywhere, including the header and Three-Week Lookahead. Added Forgot Password email recovery and secure new-password flow.
V10.1
Mobile / iPad / iPhone optimization + login logo fix. The VALBEN logo now loads directly on Sign In. The default logo is no longer embedded multiple times in the HTML, improving mobile load performance. Tablet and phone layouts add a touch-friendly bottom navigation, compact header, smooth Schedule scrolling, Safari anti-zoom inputs, swipeable Calendar, and mobile-friendly dialogs while preserving the Windows desktop layout.
V10.2
Project Control essentials. Added activity Blockers, Dashboard Needs Attention for today and the next 7 days, and a simple Baseline vs Current variance. These three additions are intentionally lightweight so the app remains fast and easy to learn.
V10.3
Schedule layout optimization. The bottom horizontal control now moves the complete Schedule instead of leaving the task table fixed. Added Full Detail and 3-Week Fit modes. On iPad/iPhone the Schedule opens in a compact 3-week timeline view by default, while Full Detail remains available for editing every field.
